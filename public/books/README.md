# Hostable open textbooks

Files in this folder are served by the Books page ("Read here").

## When a title may be hosted here

Only if **all** are true:

1. Explicit redistribution licence on the source page (**CC BY**, **BY-SA**, **BY-NC**, **BY-NC-SA**, public domain / **CC0**), or the author’s own work.
2. PDF/EPUB actually present in this folder.
3. Attribution kept on the Books card and the licences list.

Otherwise use **link-only** in `books.js` — never store a local copy.
